Salt Spring Island · Board game shop

A cosy little den for game lovers.

Foxes Board Game Shop is Salt Spring Island’s own board game store — a warm, wood-shelved corner of the island packed with party games, strategy classics, D&D supplements and miniatures, plus a calendar of weekly game nights.

A community fixture: the shop partners with the island library and has been name-dropped by author Austin Kleon.

Weekly at the shop

Game nights & get-togethers

Foxes isn’t just a shop — it’s where the island plays.

Sundays · 5–9pm

Mini-painting get-togethers

Bring your brushes — or start from scratch. Everything you need to get into mini painting is stocked in-store, and Sunday evenings are for painting together.

Wednesdays

Magic draft nights

Weekly Magic drafts run every Wednesday — plus seasonal fun like the Ork-tober miniature painting challenge. Check in-store or message ahead to save a seat.

New stock and event announcements currently go out on the shop’s Instagram — a permanent page would put all of this in one place for islanders and visitors alike.
